# ระบบจัดทำใบสมัครสมาชิก อวท. (แบบ อวท.๑๐)

## 📖 เกี่ยวกับโครงการ (About)
ระบบจัดทำและพิมพ์เอกสารราชการ **"แบบ อวท.๑๐" (ใบสมัครสมาชิกองค์การนักวิชาชีพในอนาคตแห่งประเทศไทย ระดับสถานศึกษา)** พัฒนาขึ้นเพื่ออำนวยความสะดวกแก่นักเรียน นักศึกษา ครู และเจ้าหน้าที่ในสถานศึกษาสายอาชีวศึกษา (วิทยาลัยเทคนิค / วิทยาลัยอาชีวศึกษา / วิทยาลัยสารพัดช่าง) ทั่วประเทศ

ระบบช่วยแก้ปัญหาความยุ่งยากในการเขียนเอกสารด้วยลายมือ ปัญหาวรรณยุกต์ลอย หรือเอกสารตกบรรทัด โดยมีระบบกรอกข้อมูลที่ทันสมัย ซิงค์ข้อมูลลงในหน้ากระดาษ A4 เสมือนจริงแบบเรียลไทม์ และสามารถสั่งพิมพ์หรือดาวน์โหลดเป็นไฟล์ PDF คุณภาพสูงได้ในคลิกเดียว

## ✨ คุณสมบัติเด่น (Key Features)

- 🏫 **ระบบสะท้อนข้อมูลอัจฉริยะ (Smart Auto-sync):**
  - กรอกชื่อวิทยาลัยจุดเดียว ระบบจะกระจายไปยังทุกตำแหน่งในเอกสารอัตโนมัติ
  - ป้องกันคำซ้ำซ้อน (เช่น พิมพ์ "เทคนิคกรุงเทพ" หรือ "วิทยาลัยเทคนิคกรุงเทพ" ก็จะแสดงผลถูกต้องเสมอ)
  - ใส่วันที่ เดือน และ พ.ศ. ปัจจุบันให้อัตโนมัติ

- ✍️ **รองรับลายมือชื่อดิจิทัล (Dual Signature System):**
  - มี Signature Pad ในตัว รองรับการใช้นิ้ววาดลายเซ็นบนหน้าจอมือถือ/แท็บเล็ต หรือใช้เมาส์บนคอมพิวเตอร์
  - หากไม่ต้องการเซ็นออนไลน์ สามารถเว้นว่างไว้เพื่อพิมพ์ออกมาลงลายมือชื่อจริงด้วยปากกาได้

- 📄 **สร้างไฟล์ PDF แท้ & พิมพ์ A4 พอดีหน้าเดียวจบ:**
  - ปุ่ม **"Submit & ดาวน์โหลด PDF"**: สร้างและดาวน์โหลดไฟล์ `.pdf` แท้ลงเครื่องทันที (ไม่มีส่วนหัว/ท้ายของเบราว์เซอร์ติดมา)
  - ปุ่ม **"พิมพ์ (Print)"**: สั่งพิมพ์แบบ Vector คมชัดสูง ปิดการแสดงวันที่/URL อัตโนมัติ จัดหน้าพอดีกระดาษ A4 หน้าเดียว ไม่ล้นไปหน้า 2

- 📱 **รองรับทุกอุปกรณ์ (Responsive Hybrid Design):**
  - **บนคอมพิวเตอร์:** แสดงแบบ Split View (ฝั่งซ้ายกรอกฟอร์ม ฝั่งขวาพรีวิวเอกสารสด)
  - **บนมือถือ/แท็บเล็ต:** ปรับเป็นฟอร์มเต็มจอ ใช้งานง่าย สะดวกทุกที่ทุกเวลา
  - มีปุ่มสลับมุมมอง: `พรีวิวคู่ฟอร์ม`, `ดูเอกสารเต็มจอ` และ `ฟอร์มอย่างเดียว`

- ⚡ **Zero Dependency & Standalone:**
  - เป็น Pure Client-side Web App ฝังตราสัญลักษณ์ อวท. และฟอนต์มาตรฐานในตัว
  - สามารถบันทึกไฟล์ `index.html` ไปเปิดใช้งานแบบ Offline บนคอมพิวเตอร์ได้โดยไม่ต้องต่ออินเทอร์เน็ต

## 🛠️ โครงสร้างแบบฟอร์ม แบบ อวท.๑๐
1. **ส่วนหัวเอกสาร:** ตราสัญลักษณ์ อวท. ต้นฉบับ, หัวข้อระเบียบแบบ อวท.๑๐, ชื่อสถานศึกษา และวันที่จัดทำ
2. **ข้อมูลผู้สมัคร:** คำนำหน้า, ชื่อ-สกุล, ระดับชั้น, รหัสประจำตัว, สาขาวิชา, สาขางาน, วันเดือนปีเกิด
3. **ที่อยู่และการติดต่อ:** บ้านเลขที่, ซอย, ถนน, ตำบล, อำเภอ, จังหวัด, รหัสไปรษณีย์, เบอร์โทรศัพท์
4. **ข้อมูลครอบครัว & คำรับรองผู้ปกครอง:** ชื่อบิดา, มารดา, ชื่อผู้ปกครอง และคำรับรองให้ความยินยอมตามระเบียบ
5. **คำปฏิญาณ 3 ข้อ:** จงรักภักดีต่อชาติ ศาสนา พระมหากษัตริย์, บริการสังคมด้วยจิตสาธารณะ, และยึดมั่นในคติพจน์จรรยาบรรณวิชาชีพ
6. **ส่วนบันทึกนายทะเบียน:** บันทึกการพ้นสภาพสมาชิกในอนาคต
